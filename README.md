# iPod\_Classic-Universal-USB-C-Mod

\# 🎵 Universal USB-C Modkit for iPod Classic \& Video (5th - 7th Gen)



An original, high-precision PCB modkit engineered, routed, and hand-crafted in KiCad to replace the legacy 30-pin Apple dock connector with a modern \*\*USB-C Port\*\* supporting both charging and high-speed data synchronization.



Designed \& Engineered by a \*\*Thai University Student\*\* / Founder of \*\*Retro iPod Studio in Bangkok\*\* 🇹🇭.

\## 🎓 About The Project



This project started as a personal passion project during my university studies to modernize classic hardware and solve the limitations of aging 30-pin cables. Every trace, component footprint, and clearance constraint was custom-routed from scratch to achieve a seamless, professional drop-in fit.



\---



\## 🎯 Universal Compatibility



Engineered with precise trace width and mechanical tolerances to fit seamlessly across all classic 30-pin dock iPod logic boards:



\* \*\*iPod Video (5th Gen)\*\* — 30GB / 60GB / 80GB

\* \*\*iPod Video Enhanced (5.5th Gen)\*\* — 30GB / 80GB

\* \*\*iPod Classic (6th Gen)\*\* — 80GB / 160GB Thick

\* \*\*iPod Classic (6.5th Gen)\*\* — 120GB

\* \*\*iPod Classic (7th Gen)\*\* — 160GB Thin

\## ✨ Hardware \& Circuit Engineering Highlights



\* \*\*🔌 Native USB-C Connector:\*\* Surface-mount USB-C receptacle with mid-mount legs engineered for maximum mechanical durability during cable insertion.

\* \*\*⚡ USB-PD Compatibility:\*\* Integrated dual $5.1\\text{k}\\Omega$ SMD pulldown resistors on $CC1$ / $CC2$ lines to allow seamless charging via USB-C Power Delivery (C-to-C) chargers and modern Mac/PC hardware.

\* \*\*⚡ Castellated Edge Pads:\*\* High-precision half-vias along the board perimeter for easy drop-in alignment and direct soldering to the original dock pads.

\* \*\*💾 Full Sync Capabilities:\*\* Optimized differential routing for $D+$ and $D-$ lines ensuring reliable data transfer and syncing with Finder / iTunes / Rockbox.

\* \*\*🛠️ Compact Ultra-Thin Clearance:\*\* Custom PCB outline designed specifically to fit both Thin and Thick rear housing shells without interference.
